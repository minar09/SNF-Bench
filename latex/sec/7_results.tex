\paragraph{Motion persistence.} Dynamic-region behaviour is read at the joint point $\bigl(\mathrm{MCFF}(\mathcal{L}),\,\mathrm{FP}\bigr)$, never FP alone: sustained flow needs non-trivial late motion \emph{and} high retention. \subsection{Drift Leakage Changes the Interpretation of Apparent Motion}
\label{sec:results_drift}

The effect is systematic rather than anecdotal. Correlating each generic whole-frame metric with each SNF-Bench factor over method-level means (supplementary material), Dynamic Degree tracks static-region flow at $\rho = \SNFddNBF$, so the systems a generic metric reads as most dynamic are, closely, those whose backgrounds move most. Causal-Forcing ranks \SNFrankCFDD{} of \SNFnPublicTTV{} on Dynamic Degree and \SNFrankCFNBF{} on NBF; Infinite-Forcing mirrors it, ranking \SNFrankIFNBF{} on static fidelity and \SNFrankIFDD{} on apparent motion. Read with its magnitudes, Causal-Forcing's DLR of \SNFvalCFDLR{} indicates static-region motion energy almost equal to the region intended to move, while its DAR of \SNFvalCFDAR{} indicates a rigid global model accounts for only part of it---the remainder is non-rigid instability.


\subsection{Image-Conditioned Track: Native Capability and Deployment Sensitivity}
\label{sec:results_i2v}

Table~\ref{tab:i2v_audit} is two things, kept apart. The two unmarked rows are a \emph{native-capability} result: systems whose released configuration reaches these horizons, measured as shipped. The five marked rows are a \emph{deployment-sensitivity} panel: released checkpoints whose own configuration does not reach these horizons, run under a common long-horizon wrapper. This is not a seven-system audit and is not presented as one; ranking a marked row against an unmarked one would compare one system's design against another's deployment. The panel supports one descriptive observation: the same checkpoint under a wrapper rather than its native configuration yields materially different static-fidelity and persistence scores, so a conclusion about a system is a conclusion about that system \emph{as deployed}. Why that happens is outside what a benchmark establishes, and we do not claim it.


The track supplies what the text-conditioned one cannot: every system starts from the same source image, so static support is given rather than invented and divergence is attributable to the system. Bidirectional reference systems reach only the $5$\,s tier and are reported there.
